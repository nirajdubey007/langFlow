# ⚡ Quick Start - Deploy Your Custom Langflow (macOS)

## 🎯 3 Simple Commands

### 1. Build Your Custom Image
```bash
cd /Users/niraj/Desktop/langFlowBrained/langFlow/langflow-deployment
./build-and-test.sh
```
⏱️ Takes 15-30 minutes (first time)

### 2. Deploy Everything
```bash
./deploy.sh
```
⏱️ Takes 1-2 minutes

### 3. Open in Browser
```
http://localhost:7860
```

**Done!** 🎉
